# Castlevania: O Carmim de Báthory (Fractal RPG)

Uma adaptação de campanha e regras de **Castlevania** construída sobre o sistema narrativo [SRD Fractal RPG v1.0.3](file:///c:/Users/Admin/Vaults/Sync/Castlevania%20RPG/SRD%20Fractal%20RPG%20-%20v1.0.3.pdf).

Ambientada na **Romênia dos séculos XVI e XVII**, a campanha coloca uma aliança improvável de **Caçadores Mortais**, **Oradores Conjuradores**, **Dhampiros** e **Vampiros Renegados** contra a terrível **Condessa Elizabeth Báthory** e sua corte canibal no sombrio **Castelo Csejte**.
